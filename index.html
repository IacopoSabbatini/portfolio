Sistema de gestão para loja de moda · Projeto Integrador

Sistema desktop com Java Swing e banco de dados MySQL para administrar uma loja de roupas de ponta a ponta: autenticação, cadastro, vendas e finanças, tudo conectado ao mesmo banco.

  • Login e cadastro de administradores no banco de dados
  • Cadastro de clientes e produtos
  • Registro de vendas e controle de estoque
  • Controle de caixa e relatórios financeiros
